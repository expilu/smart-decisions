# smart-decisions

A TypeScript library that returns choices from System 1 (fast, logit-based)
or System 2 (deliberate, LLM structured output) intelligence.

> ⚠️ **Pre-1.0 / work in progress.** The API is not stable yet.

## Install

```bash
npm install smart-decisions
```

Usage

``typescript
import { choices } from "smart-decisions";

console.log(choices());
